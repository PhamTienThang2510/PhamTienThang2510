- 💡 **Kỹ năng mở rộng**: Nền tảng lập trình hướng đối tượng (OOP), cấu trúc dữ liệu & giải thuật, shader cơ bản (ShaderLab), cùng tư duy AI (Transformers/NLP) và phát triển ứng dụng di động.

- 🔍 **Pipeline AI**: comic-text-detector (ONNX) + manga-ocr / EasyOCR + LaMa inpainting trên PyTorch (CUDA / CPU); tự dò & xoá chữ còn sót, nhận diện loại bong bóng thoại.
- 🧠 **Dịch theo ngữ cảnh cả chương** với Claude / Gemini / OpenAI / LM Studio / Ollama + glossary tên riêng & xưng hô.
- ✏️ **Editor trực quan**: so sánh trước/sau, kéo thả ô chữ, chữ hiển thị trực tiếp (WYSIWYG), thư viện font tiếng Việt có kiểm tra dấu.
- 📦 **Đóng gói & bảo mật**: bộ cài Electron tự cài engine Python qua `uv`, model tải từ nguồn gốc có kiểm tra SHA-256, API key mã hoá Windows DPAPI.
